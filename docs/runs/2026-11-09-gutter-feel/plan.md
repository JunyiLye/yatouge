# 水溝過彎手感：車身下沉、穩定卡住、轉向即可脫出 — 實作計畫

結論：調整已上線的水溝過彎（見 `../2026-11-09-seiran-gutters/`），共三項：
- 卡進水溝時，車身明顯往內側下沉，看起來像輪子真的掉進溝裡。
- 卡住之後只要不打方向、不加速超過上限，車子就會一直留在溝裡，直到溝的盡頭。
- 卡住滿 1 秒後，按左或右任一方向鍵都會立刻脫出。

Pipeline：Frontend Feature SDD — Light Path（單一檔案、無 API、無新相依）。

## 使用者需求（2026-11-09 原話）
「when ur in a gutter run the car feels drop inside a bit like the car actually drop into a gutter and when inside a gutter run, when u didnt do left or right arrow or didnt accelerate too fast the car will not go out of the gutter, but when u do a left or right u can get out the gutter immediately (oh ya it should be in the gutter for like 1s before u can get out)」

**假設**：左右任一方向都能脫出。因為水溝的內側緊貼護欄，脫出時車子一律往路面方向（溝的反方向）爬出，不會往牆那邊。狀態：在回覆中告知使用者。

## 設計
1. **下沉外觀**（只影響外觀，不影響物理）：
   - 卡水溝時，車身高度平滑降低約 0.12 m（與溝深相同），往內側的傾斜從 0.05 rad 加大到約 0.10 rad。
   - 進出水溝用平滑過渡，約 0.12 秒。
   - 卡入的瞬間加一下短促的鏡頭震動，代表「咚」一聲掉進去。
2. **穩定卡住**：
   - 卡住時橫向位置不再往外飄，固定在進入時的位置，並限制在 3.7–4.1 之間。目前會從 3.93 慢慢飄到 4.19。
   - 卡住時不會因為速度或角度門檻而脫出。
   - 只有三種情況會離開：到達有效範圍盡頭（s1−3）、打方向脫出、速度超過上限。
3. **超速彈出**：卡住時速度超過 `MAX_V`（24 m/s），不再把速度壓在上限，而是直接彈出水溝、回到一般物理。玩家必須自己控制油門。
4. **方向鍵脫出**：
   - 卡住時間滿 1 秒後，只要有左或右的方向輸入（`|steer|` > 約 0.3，`steer` 是 −1 到 1 之間的平滑值），就在同一步脫出。
   - 未滿 1 秒時按方向鍵沒有作用，車子仍然卡住。
   - 脫出時給車子一個往路面方向（溝的反方向）約 2.5 m/s 的橫向速度，讓車確實爬出溝。
   - 脫出後，直到車子離開進入帶（`|lat|` < 3.6）或經過 0.6 秒，都不會在同一段重新卡入，避免下一步又被吸回去。重新卡入時不重複扣分，維持原本「同一段、同一趟只扣一次」的規則。
5. 其他規則全部不變：扣分、撞牆懲罰、碰護欄 1 秒、頭尾 3 m 漸變。

## 任務
1. **純函式層**：先寫測試，再實作。
   - (a) 卡住後不打方向、不給油，以固定步長沿每個彎模擬到 s1−3：全程維持卡住，橫向位置與進入時相差在 0.05 m 以內。
   - (b) 卡住 0.5 秒時按方向（左、右各測一次）：仍然卡住。
   - (c) 卡住 1.1 秒時按左、按右：各自一步內脫出，且有往路面方向的橫向速度。
   - (d) 卡住時速度 24.5：彈出。
   - (e) 脫出後 0.3 秒內、仍在進入帶：不重新卡入。離開進入帶或經過 0.6 秒後可以重新卡入，而且不扣分。

   既有測試要維持通過。如果因為「固定橫向位置」而必須調整斷言，要在報告中說明。
2. **接進 `physics()` 與外觀**：
   - 需要的狀態（卡住時間、脫出冷卻、進入時的橫向位置）放在 `car` 上，並在 `resetRace` 與 `resetCar` 初始化。
   - 下沉與傾斜做在 `placeCars`。
   - 卡入的瞬間呼叫 `shake`。
   - 外觀部分沒有純邏輯可測，由瀏覽器驗證。

## Exit Criteria
1. 從專案根目錄執行 `node --test` 全部通過，0 個失敗。
2. 任務 1 的 (a)–(e) 都有持久化測試，先紅後綠。
3. 瀏覽器實測（固定步長 harness）：
   - 在第 2 個彎以 18 m/s、1,000 分卡入，不按任何鍵、不給油：一直卡到 s1−3。
   - 卡入後 0.5 秒按住方向鍵：仍然卡住。
   - 1.2 秒時按住方向鍵：0.1 秒內脫出，之後不會馬上被吸回去。
   - 卡住時的截圖看得到車身下沉、往內側傾。
4. 先前通過的情境仍然通過：
   - 撞上第 2 彎外側護欄、貼著滑進第 3 彎時不扣分。
   - 頭尾漸變處不卡。
   - Console 沒有錯誤。
5. Build / lint：N/A。
