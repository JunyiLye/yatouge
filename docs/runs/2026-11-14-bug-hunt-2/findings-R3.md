# 第二次深度檢查 R3：車輛、物理、AI（yatouge.html 2579–3658，main c756e2f）

結論：沒有當機、NaN、GPU 洩漏或瞬移；找到三個低嚴重度 bug，都不是 C1／C2 修正造成的退步。`node --test` 697 項通過。

## R3-1（低）車內視角時在遊戲內選單重新開啟車門字樣，字樣會單獨浮在隱藏的車身外
- 位置：`setKx`（4807）直接設 `c.door.visible = on`，沒有像 `syncBody`（4473）一樣看 `hide`；`syncBody` 因為 `playerCar === bodyCar && hide === bodyHidden` 提早返回，不會改回來。
- 重現：KX-2 車內視角（或送酒模式）比賽中，選單 → 設定 → 車門字樣關再開，`playerCar.door.visible` 變成 true，其他車身都隱藏；右後照鏡可能照到。
- 預期：車身隱藏時車門字樣也隱藏。信心：狀態高；鏡中可見程度中。

## R3-2（低）`resetRace` 沒有重設 `car.gas`／`car.brakeOn`，上一場的「踩油門」延續到下一場倒數
- 位置：`resetRace`（3471–3478）；`physics()`（3609）只在 race/done 寫入；倒數時 `updateEngineAudio`（3899、3904、3926）讀 `car.gas`。
- 重現：比賽中按住油門，選單 → 重新開始，放開油門；整個倒數引擎聲維持踩油門的音量，GT-32／SR-7 渦輪聲也會出現，直到 GO。
- 預期：每場開始 `gas = false, brakeOn = false`。信心：高（只影響聲音）。

## R3-3（低）AI 的完賽時間比玩家早記一幀，同一幀衝線一定判 AI 贏
- 位置：`rivalUpdate`（3656）`rivalFinishT = raceT` 在 `raceT += dt`（6193）之前；玩家 `finishRace`（4560）在之後記 `playerFinishT = raceT`。
- 影響：對 AI 的成績差距固定偏一幀（約 16.7 ms，最多 50 ms）對玩家不利；只有同一幀衝線時勝負會不同。
- 預期：兩者用同一個時鐘記錄（AI 記 `raceT + dt`）。信心：高。

## 檢查過、沒發現問題
終點後停車（C1）、AI 衝線後（C2）、換車／換賽道／換模式的釋放、`locate`／`samplePos`、上下坡 AI、顏色鎖、KX 升級套用、觸控與傾斜的純函式。

## 可能是設計問題（不是 bug，不修）
- 送酒模式解鎖的 KX-2 極速升級在線上 1 對 1 也有效，解鎖玩家的 KX-2 比對手原廠的快。
- AI 依距離調整速度（×0.85／×0.94／×1.08）是刻意的追趕機制。
- 重新開始或換賽道後，上一場的輪胎煙（約 1.6 秒淡出）仍看得到。
- `wrapDecal` 射線沒打到車身時頂點會落在射線起點，只在貼花超出車身時才有風險。
- 衝線後兩車可能重疊（第 3 批已接受）。
