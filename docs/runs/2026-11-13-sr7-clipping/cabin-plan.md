# SR-7 車艙重做 — 使用者回饋（2026-11-13）

結論：上一輪修穿模（commit aec704f）之後，使用者認為 SR-7 的車頂很怪，左右車窗太大。參考照片是 images/26.png（黃色 FD，前左斜角）與 images/27.png（黃色模型車，前左上方）。這一輪重做整個車艙。車頭、車尾、尾翼、輪拱與車身下半部都不動。

## 問題
- 車艙像一整顆玻璃泡泡，側窗幾乎占滿車身的長度，一路往下延伸到葉子板附近。
- 車頂沒有明確的車身色區塊，也看不出前後窗的分界。

## 目標（依照片）
- **側窗**：小、短、呈淚滴形，位置高。窗下方有大面積的車身色。
- **車頂**：車身色、偏窄，往後圓順地下彎，接到一大片傾斜的後擋玻璃（掀背玻璃）。
- **肩線**：高且圓潤，包住車艙，讓車艙看起來小而且偏後。
- **前擋**：傾斜，A 柱是黑色，玻璃四周有清楚的黑框。
- **車門**：照片中有車門分縫線與小的門把，車門後方有側面進氣口造型（可選）。

## 車尾（使用者追加，參考 images/28.png）
使用者問「排氣管下面那條黑色橫條是什麼」，並附上正確的車尾照片。

- **黑色橫條**：保險桿下方有一整條黑色板子，是代替車底與擴散器的平面。照片中沒有這條：黃色保險桿往下包住車底，下面只看得到陰影。把它移除，或改成從後方平視看不到的深色車底，不能露出一條黑色橫條。
- **尾燈**：照片中是一條橫跨車尾的煙燻深色燈條，兩端是尾燈，中間是深色面板。現在的黑色面板上有四顆分開的紅色圓燈，要改得接近照片。
- **尾翼**：照片中是車身色的環形尾翼（hoop wing），貼近掀背玻璃，高度低，左右兩端往下接到車身。現在是黑色立柱撐起的高 GT 尾翼，要改成照片的樣式。
- **車牌與保險桿**：車牌在保險桿中央；兩側有細長的紅色反光片；單出圓形排氣管在右側（車子的右邊）。
- 不使用任何真實品牌標誌，車牌不放文字。

## 驗證
- 修改前後從 fl、side、top、roof、roofside、rear、corner 拍照，並把修改後的照片與參考照片並排比對：側窗高度占車身側面的比例、車頂寬度、後擋大小都要接近照片。
- KX-2 與 GT-32 的照片修改前後必須完全相同。
- 從專案根目錄執行 `node --test` 全部通過。
- 一次只開一個瀏覽器、一個分頁；結束時關閉。
