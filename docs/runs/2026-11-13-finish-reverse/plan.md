# 衝線後車子倒車

## 現象
比賽結束後，車子先煞停，接著開始往後倒車。

## 根本原因
衝線後 `physics()` 會強制 `brake = true`（轉向 0、不給油）。`vehicleAccel` 裡「煞車且接近靜止、沒踩油門」是刻意設計的倒車蠕行（最高 -6 m/s）。車一停下來，自動煞車就變成倒車。所有會進入 `done` 的模式（競速、計時賽、送酒成功與失敗、線上、貓捉老鼠）都走同一條路徑。

## 修法
`physics()` 在 `done` 狀態傳入 `u.hold = true`。`vehicleAccel` 在 `hold` 且煞車且前進速度 ≤ 0.5 m/s 時，直接回傳 `-vf / dt`，讓這一步結束時前進速度剛好為 0。這同時抵消下坡重力，所以車不會倒滾也不會前滑。速度高於 0.5 m/s 時仍用原本的煞車力。

## 不變的部分
- 比賽中玩家的煞車、倒車蠕行、手煞車、檔位與引擎煞車完全不變（`hold` 只由衝線後的自動煞車設定）。
- 沒有新增設定、聲音或外觀變動。

## Exit Criteria
- 新測試：衝線自動煞車從 20 m/s、坡度 0 / 0.05 / 0.1 煞 12 秒，前進速度結束時約 0 且從不為負。
- 新測試：一般煞車（無 hold）仍會蠕行到約 -6 m/s。
- `node --test` 全數通過；CR 0、`__lc` 0、無隱形字元、最後一個 script 可解析。
- 尚未實機試玩，需使用者在遊戲中確認衝線後車子停住。
