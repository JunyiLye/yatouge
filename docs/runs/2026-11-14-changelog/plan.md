# 進入遊戲時顯示更新紀錄（2026-11-14）

結論：玩家打開遊戲時，如果有自己還沒看過的新版本，主畫面會跳出一個「更新內容」視窗，列出新版本的重點（中英文）；看過就不再自動跳出，主畫面另有按鈕可以隨時再打開。

## 使用者需求
「我希望你可以讓玩家在遊戲進入時看到更新 log」。使用者離開期間授權我自己選推薦方案，最後寫結論。

## 決定（推薦方案，使用者可推翻）
1. **什麼時候自動跳出**：載入後在主畫面，當最新版本比玩家上次看過的新（localStorage `yatouge-log-seen` 存看過的版本）時自動打開一次；關掉就記錄為已看過。
   - 第一次來的新玩家也會看到（只顯示最新一版的內容），之後同一版不再跳出。
   - 只在主畫面跳出；如果載入時已經進入線上大廳或比賽（例如網址帶參數），就不跳。
   - 其他方案：只顯示一個「有更新」小紅點，不自動跳出（較不打擾，但玩家容易錯過）；每次載入都跳（太煩）。
2. **再看一次**：主畫面加一顆「更新內容」按鈕，打開完整紀錄（最近的版本在最上面，捲動看舊的）。
3. **內容格式**：每個版本一個日期（例如 2026-11-14）與 3–8 條玩家看得懂的重點，中英文各一份；不寫技術細節。資料放在可測試的純函式區塊 `@changelog`，最多保留最近 12 個版本。
4. **介面**：沿用現有對話框樣式（像暱稱、按鍵設定）；`role="dialog"`、`aria-modal`、焦點鎖在視窗內；Esc、手把 B、點「知道了」關閉；手機橫向可捲動不超出畫面。
5. **之後的維護**：在 `CLAUDE.md` 的改動流程加一條：「玩家看得到的改動推上去時，要在 `@changelog` 新增或補充當天的版本」，避免紀錄停更。

- 換行只有 LF、沒有 `__lc`、沒有隱形字元，script 可以解析，頁面載入沒有錯誤（含宣告順序回歸測試）。
