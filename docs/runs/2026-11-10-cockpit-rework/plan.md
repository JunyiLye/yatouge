# 車內視角重做 — 實作計畫

結論：把車內視角從平面疊圖改成真正的 3D 車內，三台車各有自己的內裝風格：
- 方向盤會照玩家的轉向輸入轉動；
- 排檔桿在換檔時有動畫；
- 儀表的指針會動；
- 加上左右兩側的後照鏡；
- 調整座位、眼睛高度與視角；
- 視角會隨 G 力傾斜、往彎道內看，並隨車速與撞擊震動。

Pipeline：Frontend Feature SDD — Light Path（單一檔案、無 API、無新相依、無安全面）。

## 使用者需求（2026-11-10）
使用者勾選了：Real 3D interior、Better view position、Alive camera motion、Side mirrors，並補充：「make so that the steering move according to your input and gear shift animation」。

## 現況
- `cockpit` 鏡頭模式：眼睛位置來自 `cockpitLocal(CAR_BOX)`，右駕，`local x = -0.35`，高 1.05。
- 車內框（A 柱、儀表板、方向盤圈）是 HTML 疊圖 `#cockpit`。
- 中央後照鏡畫到 render target，再顯示在正交疊加場景。
- 在 cockpit 模式時，`syncBody` 會隱藏車身。
- 檔位在 HUD 計算（`GEARS` 門檻），轉向是 `c.steer`（−1 到 1，平滑過）。
- 三台車：hatch（KX-2）、coupe（SR-7）、gtr（GT-32）。

## 設計
1. **3D 車內（取代 HTML 疊圖）**：
   - 車內 mesh 掛在玩家車的 group 上，只在 cockpit 模式顯示。
   - 包含：
     - 儀表板：上緣有弧度，顏色深色；
     - 儀表罩與兩到三個圓形儀表，至少有轉速表和速度表，指針是 mesh，會隨數值旋轉；
     - 方向盤：3D 圈加輻條，跟轉向柱連接；
     - A 柱、車頂前緣、遮陽板；
     - 中控台與排檔桿（球頭加防塵套）；
     - 門板上緣與窗框；
     - 前擋玻璃邊框。
   - 依車型做參數化的差異：
     - KX-2：80 年代方正儀表板、三輻方向盤、黑灰內裝；
     - SR-7：90 年代弧形環繞座艙、中央大轉速表、三輻方向盤；
     - GT-32：方正儀表板、中控台三個小錶、四輻或三輻方向盤。
   - 共用一個建構函式，用參數區分車型，不要寫三份。
   - 移除 HTML 的 `#cockpit` 疊圖。若手機排版需要它，保留只有幾何、不擋視線的最小部分；以 3D 為主。
2. **座位與視角**：
   - 依各車的 `CAR_BOX` 與車頂高度，重新決定眼睛的位置。
   - 調整到看得到引擎蓋的後段、路面，以及大部分的儀表；儀表板遮住畫面下方約 25–35%。
   - FOV 約 70–80，可以隨速度微調。
   - 右駕，方向盤在右側。
3. **方向盤與排檔桿動畫**：
   - 方向盤的轉角 = `c.steer` × 約 270°，使用已經平滑過的值。
   - 排檔桿用 H 檔排列（5 速加 R）：1 左前、2 左後、3 中前、4 中後、5 右前、R 右後。
   - 換檔時，排檔桿在約 0.18 秒內，沿 H 檔的路徑（先回中線、橫移、再推入）移到新的檔位。
   - 檔位用和 HUD 相同的規則計算；可以抽成共用的純函式。
4. **儀表指針**：
   - 轉速表依 `car.rpm`，0–9000。
   - 速度表依車速 km/h，0–260。
   - 指針轉動要平滑。
5. **兩側後照鏡**：
   - 左右車門外各有一面 3D 後照鏡，鏡面貼上 render target，左右反轉，看往車後的左右兩側。
   - 解析度要低，約 128×80。
   - 兩面側鏡輪流更新（每幀只更新一面），以節省效能。
   - 中央後照鏡維持現在的做法，或改成 3D 的車內後照鏡，由 maker 決定，但外觀要一致。
   - 只在 cockpit 模式時才渲染這些鏡子。
6. **活的鏡頭**（純函式 `cockpitMotion`，輸入加速度、角速度、速度、轉向、撞擊）：
   - 側向 G 讓頭部往彎道外側移動並微微側傾，限制在約 ±4 cm、±3°。
   - 縱向 G（煞車、加速）讓頭部前後移動並微微俯仰。
   - 往彎道內看：視線往轉向與角速度的方向偏，最多約 8°。
   - 路面震動依車速，振幅很小；撞牆時依撞擊量做一次短暫的晃動，沿用 `shake`。
   - 所有變化都要平滑，不能讓人暈。
7. **相容性**：
   - 主畫面、chase、near 模式都不受影響。
   - 從 cockpit 切出去後，車內 mesh 要隱藏，鏡子也停止渲染。
   - PvP 對手的車不顯示車內。
   - 切換車型時重建車內並 dispose。

## Exit Criteria
1. 從專案根目錄執行 `node --test` 全部通過，0 個失敗。下列純函式的測試要先紅後綠：
   - 方向盤轉角對照；
   - 排檔桿的 H 檔位置與換檔路徑；
   - 儀表指針的角度對照；
   - `cockpitMotion` 的上限與平滑；
   - 檔位的共用函式（若有抽出）。
2. 瀏覽器實測，三台車都要做：
   - cockpit 模式下看得到 3D 車內，不會穿模；
   - 轉向時方向盤轉動、換檔時排檔桿移動、指針會動（截圖為證）；
   - 兩側後照鏡顯示車後的畫面，而且左右反轉；
   - 甩尾與煞車時，視角有自然的晃動；
   - 切回 chase 時，車內不會殘留。
3. 效能：在 cockpit 模式下，記憶體的 geometries 與 textures 數量維持穩定。與現在相比，FPS 不能大幅下降；headless 只作參考。
4. 手機寬度（390）的 cockpit 畫面可以正常遊玩。
5. console 沒有錯誤。結束時關閉所有測試 server 與瀏覽器。
