# 遊戲內選單：重新開始與回到大廳（2026-11-13）

結論：單機比賽的遊戲內選單加一顆「重新開始」，不必先認輸再從主畫面重來；線上比賽的選單加一顆「回到大廳」，經過確認後離開這場比賽、回到線上大廳，不必先回主畫面再重新進線上。

## 使用者需求
- ingame menu should add a restart button for local gameplay (instead of forfeit and start again)
- add a back to lobby button for online game

## 現況
- 選單（`#igmenu`）只在倒數與比賽中能打開，主畫面有「繼續、設定、聊天（線上）、認輸」。
- 認輸（`forfeit`）在單機回主畫面（`returnToTitle`），線上呼叫 `pvpLeave` 回主畫面。
- 計時賽與送酒模式中，「認輸」顯示為「放棄」。

## 決定（Light Path：沒有 API、只動一個檔案、沒有新套件；以下是本計畫採用的假設，使用者可推翻）
1. **重新開始（單機：一般對 AI、計時賽、送酒）**
   - 只在非線上時顯示；線上時隱藏。
   - 按下後不確認，直接：關閉選單 → 結束目前的計時賽／送酒狀態（`taEnd`、`sakeEnd`，與 `returnToTitle` 相同的清理）→ `startRace()` 重新倒數。
   - 沿用目前的車、顏色、賽道、模式與變速箱（不再跳變速箱詢問）。
   - 與認輸相同，這一趟不儲存最佳紀錄。
2. **回到大廳（線上）**
   - 只在線上比賽時顯示；單機時隱藏。
   - 按下後進入確認畫面（沿用 `#igConf`，問句與按鈕文字換成回到大廳的版本），確認後：關閉選單 → `leaveToLobby`（保留暱稱，回到線上大廳）。取消回到主選單並把焦點放回「回到大廳」。
   - 原本的「認輸」（回主畫面）保留不動。
3. 新增可測試的純函式於 `@ingame-menu` 區塊，例如 `menuItems(isPvp) → { restart, lobby }`，決定兩顆按鈕的顯示。
4. 新增中英文字串：重新開始／Restart、回到大廳／Back to lobby、確定回到大廳？這場比賽會中止。／Back to the lobby? This race will end.、是，回到大廳／Yes, back to lobby（以及需要時的提示）。
5. Esc 從確認畫面返回時，焦點回到觸發確認的那顆按鈕（認輸或回到大廳）。
6. 手把的選單導覽只看可見的按鈕，隱藏的按鈕自然被略過，不需另外處理。

## 不變
- 認輸、設定、聊天的行為；比賽本身、計時、紀錄儲存規則；觀戰模式（觀戰時本來就不能開選單）。

## 第二輪
- 使用者決定「重新開始」也要先確認：按下後進入確認畫面（問句：確定重新開始？這一趟的成績不會儲存。），按「是」才重新倒數；取消或 Esc 回到主選單並把焦點放回「重新開始」。
- 確認畫面的問句與按鈕文字改由 `@ingame-menu` 的純函式 `confirmKeys` 決定（認輸、回到大廳、重新開始三種），並有單元測試。
- 審查的小問題已修正：回到大廳的防呆分支先 `syncMenuUI()` 再回主選單；重新開始時把座艙慣性的上一幀速度作廢（`_ckPrev.ok = false`），避免第一幀鏡頭抖動；重新開始時隱藏「已認輸」提示並清掉其計時器。
