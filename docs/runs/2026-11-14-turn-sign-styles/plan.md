# 彎道提示的顯示方式可選（2026-11-14）

結論：設定裡的「彎道提示」從開／關改成可選的顯示方式：側邊（現在的樣子）、大型置中、預告列（同時看到接下來兩個彎）、只有聲音、關閉。預設維持現在的「側邊」，選「側邊」時畫面與聲音和現在完全相同。

## 使用者需求
「turn indicators 目前的樣子 ok，但我希望可以讓玩家選要怎麼顯示，像是在螢幕上放顯示（大個），還有其他顯示方法你可以 brainstorm 一下」。使用者離開期間授權我自己選推薦方案，最後寫結論。

## Brainstorm（考慮過的方式）
| 方式 | 說明 | 決定 |
|---|---|---|
| 側邊（現在） | 畫面上方、轉彎那一側的中型圖示 | 保留，預設 |
| 大型置中 | 畫面上半部中央的大圖示（約現在的 2 倍），街機感最強；在車內視角會放在後照鏡下方 | **採用** |
| 預告列 | 畫面上方一條小列，同時顯示「下一個彎＋再下一個彎」兩個圖示（第二個較小、較淡），適合連續彎多的青嵐峠 | **採用** |
| 只有聲音 | 不顯示圖示，只保留嗶聲（髮夾彎兩聲） | **採用** |
| 關閉 | 沒有圖示也沒有聲音 | 保留（原本的關） |
| 路邊 3D 箭頭看板 | 在護欄外放真的箭頭看板 | 不做：工程大、遠處看不清，之前 Design Gate 也選了螢幕告示牌 |
| 地面箭頭／路面標線 | 在路面畫箭頭 | 不做：甩尾時視線不在路面，且會改變賽道外觀 |
| 畫面邊緣光暈 | 轉彎那一側的畫面邊緣發出顏色光暈 | 不做：資訊量少，分不出彎的大小 |
| 語音報路 | 合成語音唸「右三」之類 | 不做：需要語音素材或 TTS，品質不穩 |

## 決定（推薦方案，使用者可推翻）
1. 設定值：`side`（預設）、`big`、`preview`、`sound`、`off`。存在 localStorage `yatouge-turn-style`；舊的 `yatouge-turn-signs` 為 `'0'` 時視為 `off`，其他情況視為 `side`（舊玩家設定不變）。
2. 主畫面與遊戲內選單的設定都改成一個選擇器（與「鏡頭」相同的 `<select>` 樣式），標籤沿用「彎道提示」。
3. 大型置中：同一組 SVG 圖示放大，位置在上半部中央；車內視角時放在後照鏡下方，不壓到後照鏡、HUD、倒數數字；手機 844×390 縮小到不擋路面的大小。髮夾彎閃一下的動畫沿用。
4. 預告列：上方中央一條，左邊是下一個彎（正常大小），右邊是再下一個彎（約 60% 大小、較淡）；兩個彎距離很遠時只顯示下一個。用同一個 `nextSign` 的資料再往後找一個。
5. 只有聲音：照常在原本的時機嗶聲，畫面不顯示。
6. 嗶聲：所有顯示方式（關閉除外）都照原本的時機與次數。
7. 送酒模式、觀戰、倒數、結果畫面一律不顯示（與現在相同）。

## 不變
`side` 時的位置、大小、顏色、動畫、嗶聲與現在完全相同；彎道判定與分級不變。

## Exit Criteria
- 純函式（設定值解析、舊設定轉換、預告列取下兩個彎）測試先失敗、實作後通過；`node --test` 全部通過。
- 換行只有 LF、沒有 `__lc`、沒有隱形字元，script 可以解析，頁面載入沒有錯誤（含宣告順序回歸測試）。
- 瀏覽器驗證（一個 headless 瀏覽器）：五種方式各在桌機與手機橫向、追車與車內視角截圖；`side` 與改動前畫面相同；大型與預告列不壓到 HUD 與後照鏡；只有聲音與關閉時不顯示（聲音次數用計數驗證）；設定在主畫面與遊戲內選單同步並在重新整理後保留；舊設定 `yatouge-turn-signs = '0'` 轉成關閉。

## 驗證與審查紀錄
- 第一輪瀏覽器驗證：「側邊」與改動前逐像素相同、五種方式的嗶聲次數、設定同步、舊設定轉換、送酒不顯示都通過；抓到白狼峠起跑時大型／預告列與「GO」重疊、大型蓋住中央提示文字、車內第一幀後照鏡位置慢一幀。
- 修正：起跑「GO」顯示時（0.7 秒）大型與預告列先不顯示、不嗶聲，GO 結束後才出現；側邊與只有聲音維持原本時機（審查指出計畫承諾側邊不變，因此只對大型與預告列延後）。GO 狀態用會自動到期的時間（`goUntil`），不會因漏掉清除而卡住。大型與預告列出現時，中央提示文字移到圖示下方 8 px。後照鏡位置改在 HUD 之前計算。只在圖示、樣式、鏡頭或視窗大小改變時重新量位置。
- 最後一次瀏覽器驗證：60 項全部通過（含三種螢幕尺寸、追車與車內、起跑、提示文字、與改動前相同、後照鏡、縮放、整條青嵐峠嗶聲 41 次／57 聲、送酒、無頁面錯誤）。`node --test` 546 個全部通過。
- 留給使用者決定：手機橫向＋車內＋大型時，提示文字被推到儀表上，會蓋住轉速錶約 1.4 秒（字仍清楚）。

## 追加：手機提示文字位置
手機橫向車內視角搭配「大型」時，把中央提示文字推到圖示下方會蓋住轉速錶。改為：若推到圖示下方後，提示文字的下緣會超過視窗高度的 62%，就改放在圖示左側（垂直置中於圖示，右緣距圖示左緣 12 px，最大寬度為圖示左緣減 24 px，字體略小，兩行都保留）；其餘情況維持放在圖示下方。「側邊」、「只有聲音」、「關閉」不受影響。判斷寫成 `@turn-signs` 區塊裡的純函式 `tsPopPlace`，只在版面鍵改變時重算。
- 驗證：手機 844×390 車內視角的大型與預告列，提示文字改放在圖示左邊、與圖示同高，儀表不再被蓋住（截圖 `shots2/P-844-big-cockpit.png`、`P-844-preview-cockpit.png`）；桌機與手機追車視角仍放在圖示下方；`node --test` 590 個全部通過。
