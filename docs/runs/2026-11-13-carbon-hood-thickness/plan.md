# 碳纖維引擎蓋加厚

## 使用者回饋
KX-2 第 5 色（白色加碳纖維引擎蓋）外觀喜歡，但從側面看像是一張貼在引擎蓋上的紙，希望引擎蓋看得出厚度。

## 設計
- 碳纖維由 4 mm 的薄皮改成 2 cm 厚的實體面板：頂面的編織與 UV 比例不變，左右與前後緣加上側壁，下緣落在車身引擎蓋線上，沒有懸空縫隙。
- 側壁使用比編織更深的無貼圖材質。後緣從擋風玻璃底部開始，前緣停在車鼻前 5 mm，不超出車頭，也不碰燈殼。
- 壁面距車身邊緣內縮 14 mm；壁面外側有 7 mm 寬的深色分模線（引擎蓋與翼子板之間的縫），再外側是 7 mm 白色車身。
- 中央凸起面板抬高 2 cm，仍站在新頂面上。
- 車內視角的碳纖維分支用同一個函式與數字，下面另鋪白色引擎蓋面，讓壁面與分模線與外觀一致。
- 純函式 `carbonHoodStations` 放在 `@carbon-hood` 區塊供測試；舊的 `carbonStrip` 移除。

## 不變
- 編織貼圖與 `CARBON_TILE`、其他三色與其他車型、彈出式燈座 `kxPod` 的位置、共用 `carbonTex` 不被釋放、每車材質照舊釋放、幽靈車的半透明處理（會走訪所有材質）。

## Exit Criteria
- `node --test` 全數通過，含新增的 `tests/carbon-hood.test.mjs`。
- 換行為 LF、無 `__lc`、無隱形字元、最後一個 script 可解析。
- 使用者確認側面看得到厚度，且頂面不閃爍。

## 驗證紀錄
- `node --test`：508 個全部通過。
- 截圖（`before/`、`after/`，不進 git）：側面低角度與斜前方看得到約 2 cm 的板厚與深色側面、引擎蓋與翼子板間的接縫；頭燈蓋沒有穿模；車內視角正常。
- 截圖過程抓到一個執行期錯誤：`makeInterior` 的參數名稱 `carbonHood` 蓋掉了同名函式，車內視角會出錯；已改名為 `carbonOn`，並加上參數命名的回歸測試。修正後重拍沒有頁面錯誤。
- 使用者看過說明後決定直接推送，自己在遊戲中確認；這一輪沒有另外跑獨立 code review。
