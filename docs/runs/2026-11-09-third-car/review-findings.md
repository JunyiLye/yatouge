# Code Review Findings — 轉子跑車重新平衡、GT-32 與專屬聲音

結論：沒有 Critical。兩個 maker 同時修改，沒有遺失或重複的編輯。既有功能沒有退化，所有寫死兩台車的地方都已涵蓋。徽章貼圖共用、不會外洩。字串與貼圖中沒有真實品牌名稱。有 3 項 Important 和 6 項 Minor，處置等使用者決定。

審查者：fresh-context code-reviewer subagent（唯讀，沒有開瀏覽器）。`node --test` 171/171。

## Important
- **CR1 — 開 GT-32 時沒有夠快的 AI 對手**（約 1122、1128 行）
  - 開 GT-32 時，對手是 SR-7 AI（極速 50），GT-32 的極速是 70，會輕鬆勝出。
  - `CARS.gtr.ai` 這組資料從來沒有被用到。
  - 建議：開 GT-32 時把 AI 對手調強，或讓 AI 開 GT-32；否則刪掉沒用的資料。
- **CR2 — GT-32 可能難開到不行**（約 1123 行，`DRIFT_FOLLOW` 1492 行）
  - `drift` 0.72 再乘上 0.85 等於 0.61，加上 `gripLimit` 15.5 與 `slide` 0.5，可能會變成嚴重推頭，而不只是「比較硬」。
  - 測試只檢查參數的大小順序，沒有檢查實際手感。
  - 建議：用模擬比較三台車在髮夾彎的最小轉彎半徑與過彎速度。GT-32 要比 SR-7 慢，但仍然過得去。
- **CR3 — 聲音的接線沒有測試；檔位規則寫了兩份**（約 1853–1869 行）
  - 音效程式裡另外寫了一份與 `hud()` 相同的檔位計算，日後可能兩邊不一致。
  - 建議：抽出共用的 `gearOf(spd, vf)`，兩處都改用它，並補上測試。

## Minor
- CR4：同時踩油門與煞車（左腳煞車）時，洩壓閥大約每 0.6 秒觸發一次。建議煞車只在「剛踩下」那一刻觸發。
- CR5：排氣回火劈啪聲只看轉速，而且是隨機的、沒有測試。
- CR6：洩壓閥觸發時會直接把增壓值乘 0.2，等於兼做增壓模型的一部分。建議加註解說明。
- CR7：`.pick` 第三張卡片佔整排的 CSS 規則也會套用到選賽道。目前只有 2 條賽道，沒有影響。
- CR8：`makeCar` 的註解文法不通順。
- CR9：`makeCar` 裡 gtr 的分支很長，不易維護。
