# SR-7 升降式頭燈 — 使用者回饋（2026-11-13）

結論：使用者說 SR-7 重做後「其他都很好，只是升降式頭燈看起來像方塊」。這一輪只改頭燈升起時的外型，其他都不動。在 SR-7 車內視角配合完成後才做。

## 目標（參考 images/26.png、images/31.png、images/32.png）
- **蓋子**：車身色，順著翼子板的弧度，略往前傾，不是平的方塊頂面。
- **燈殼**：後窄前寬，側面與轉角都是圓的，從側面看是一片薄的楔形。
- **正面**：黑色外框，裡面是一片寬的圓角燈罩；夜間會發光（沿用目前的發光位置，必要時一起調整 `heads`）。
- **貼合**：燈殼底部與翼子板頂端貼合，沒有縫隙、沒有浮起，也沒有穿模。

## 不變
- SR-7 其他部位、KX-2 與 GT-32 的外觀（照片必須完全相同）。
- 頭燈一直是升起的狀態（目前沒有收放動作）。
- 碰撞箱、物理與車內視角；若車內看得到頭燈，車內畫面中的頭燈也跟著變成新的形狀。

## 驗證
- 拍修改前後的前左斜角、正面、側面與頭燈特寫，並與照片並排比對。
- 從專案根目錄執行 `node --test` 全部通過。
- 一次只開一個瀏覽器、一個分頁，啟動前在腳本內檢查記憶體；結束時關閉。
