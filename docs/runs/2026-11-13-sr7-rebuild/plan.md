# SR-7 從頭重做 — 實作計畫

結論：使用者看了 commit e870f3a 之後仍然覺得 SR-7「整台都很怪」，要求做得準確。逐部位修補行不通，因為問題出在車身本身的比例與形狀。這一輪依真實 FD 的尺寸與使用者提供的照片，從頭重建 SR-7 的外觀，並用與照片相同的相機角度比對輪廓，直到對得上。碰撞箱、物理與操控都不變。完成後再做 SR-7 的車內視角配合。

參考照片：images/26.png、27.png、28.png（前一輪），以及 images/29.png（後方街景）、30.png（後側斜角，含尾燈、尾翼、車窗特寫）、31.png（前左斜角，攝影棚）、32.png（模型車，上方斜角）。

## 現況的問題（與照片比對）
- **比例**：真車短、寬、曲線多，翼子板高而圓。現在的模型又長又扁，像楔形，所以上面放什麼都不對。
- **翼子板與引擎蓋**：真車的前翼子板高於引擎蓋，引擎蓋低低地夾在兩個翼子板之間。現在是一整片平斜面。
- **車艙**：真車是位在車身中段的圓潤淚滴形泡泡，前擋大而寬，後擋是弧形掀背玻璃。
- **車頭**：真車低而圓，車牌下方有一個寬的橢圓形進氣口，升降式頭燈收在翼子板頂端。現在有黑色「八字鬍」水箱罩，頭燈凸起太高。
- **輪框**：真車是大尺寸多輻輪框，塞滿輪拱。現在是小的銅色鋼絲輪框，像老爺車。
- **車尾**：後翼子板高而圓；尾燈是一條兩端圓弧的煙燻橢圓形燈條；尾翼兩端以支柱接到車身。

## 尺寸（真車，供縮放用）
- 全長約 4.29 m、全寬約 1.76 m、全高約 1.23 m、軸距約 2.43 m、前後輪距約 1.46 m。
- 輪胎外徑約 0.63 m（以照片中的輪胎占輪拱比例為準）。
- 遊戲中的 `CAR_BOX` 與物理不變；如果車身尺寸與碰撞箱差太多，回報而不是改物理。

## 做法
- 先量照片：從側面與正面照片量出車身、車窗、輪拱、引擎蓋、車頂各部位的比例（例如車窗高度占側面高度的比例、翼子板頂點高度、引擎蓋最低點）。
- 新的車身用「左右翼子板高、中間引擎蓋低」的斷面形狀，車艙用獨立的淚滴形殼，車尾翼子板高而圓。
- 用與每張照片相近的相機角度拍遊戲模型，與照片並排（montage）比對輪廓，反覆修改到輪廓吻合。
- 輪框改為深古銅色的多輻輪框（參考 images/31.png），尺寸放大到塞滿輪拱。
- 不使用任何真實品牌標誌、文字或車牌字樣。

## 不變
- KX-2 與 GT-32 的外觀（照片必須完全相同）。
- 碰撞箱、物理、車色選項、AI 對手、對戰與幽靈車的運作。

## 驗證
- 每張參考照片都要有對應角度的 montage，並由 orchestrator 親自看過才推送。
- 從專案根目錄執行 `node --test` 全部通過。
- 一次只開一個瀏覽器、一個分頁；結束時關閉。
