# 深度檢查 C：車輛、物理、AI（yatouge.html 2385–3457，main 7d36d13）

## C1（中）衝線後自動煞車遇到倒著甩尾的車，反而讓車暴衝
- 位置：`yatouge.html:3315` 的 `if (u.hold && u.brake && vf <= 0.5) return -vf / dt;`，搭配 3332–3334 甩尾分支的 `s += a * dt * Math.max(0.3, Math.cos(diff))`。
- 原因：`-vf/dt` 是為不甩尾分支設計的；衝線時若 `c.drift` 仍為 true 且車子倒著滑（diff > 90°，vf < 0），`a` 變成很大的正數，甩尾分支只套用 0.3 倍，每 1/120 秒速度乘上 (1 − 0.3·cos diff)，呈指數成長；手煞車放開後甩尾要到 |diff| < 0.12 或 s < 7 才結束。
- 重現（node）：SR-7、20 m/s、drift、hold＋煞車：diff 1.8 → 最高 27.2 m/s；2.2 → 0.2 秒到 168.7 m/s；2.8 → 0.4 秒到 26353 m/s。加上 locate、wallStep、末端擋牆，在黑鷺山以 25 m/s、車頭轉 153° 衝線：最高 338.5 m/s、撞牆 10 次，約 0.17 秒被推到賽道末端。遊戲中：終點前拉手煞車打轉，車尾朝前衝線。
- 預期：自動煞車只會讓車減速停住。
- 信心：高（node 重現）。既有的 hold 測試只涵蓋不甩尾的情況。

## C2（低）對手衝線後被釘在 `pts[N-3]`，常與玩家在終點後相撞
- 位置：`yatouge.html:3446` `r.s = Math.min(pts[N-3].s, r.s + r.v*dt)`；3445 衝線後 target = 0、減速 16 m/s²；3403–3411 `state === 'done'` 時仍執行 `carStep`。
- 原因：終點到 `pts[N-3]` 只有 25.5 m，AI 以 33–43 m/s 衝線需要 35–60 m 才停得住，所以一定被釘住，`r.v` 卻還留著原速度，停在路中央；玩家落後衝線時碰到它約 31.8 m/s，觸發 `wallHit`。玩家贏時則反過來，AI 撞上停在末端的玩家。
- 重現（node 推算）：被釘住時速度 kurosagi 40.9、seiran 33.3、hakuro 43.3 m/s；玩家 45 m/s 衝線碰到時 31.8 m/s。
- 預期：衝線後雙方在終點後不會互撞。
- 信心：中（數值與程式路徑確認，未在瀏覽器看過）。
