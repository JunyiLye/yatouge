# SR-7 引擎蓋與尾燈（2026-11-13）

結論：SR-7 引擎蓋中線比翼子板頂端低的量限制在 5 cm 以內，車內看得到引擎蓋；尾燈沿 x 軸加長約三成。同一輪也依使用者要求，把 SR-7 洩壓聲的 0.6 秒冷卻還原（commit 8460f55）。

## 使用者回饋
- SR-7 的洩壓聲改回原本的樣子（沒有冷卻）。
- SR-7 引擎蓋中間凹進去，很奇怪，車內視角特別明顯。
- SR-7 尾燈應該再長一點（x 軸方向）。

## 原因
- `CAB.coupe.body` 在 z 1.24–2.11 的斷面，翼子板頂端 `yS` 比中線 `yC` 高 9.5–15 cm。之前依 FD 照片做出「翼子板高、引擎蓋低」，但落差太深，正面看像一條溝，車內只看得到兩個頭燈凸起。
- 尾燈是 `ell(±0.6, 0.722, 0.15, 0.062)`，只佔燈條兩端一小段。

## 決定
- z = 2.11、2.02、1.85、1.6、1.24 這幾個斷面的 `yC` 改為 `max(yC, yS − 0.05)`；z 0.95 原本就只差 4 cm，不動。車頭最前面三個斷面與 0.95 以後的斷面都不動。翼子板仍高於引擎蓋。車內引擎蓋由同一組斷面產生，自動一致。
- 尾燈中心 ±0.6 → ±0.58、x 半徑 0.15 → 0.2（y 不變）；`tailsPos` 的發光位置跟著改到 ±0.58。燈條、色調、車牌不動。

## Exit Criteria
- 新測試（0.95 ≤ z ≤ 2.165 的斷面落差 0 < yS − yC ≤ 0.05）先失敗、修改後通過；`node --test` 全部通過。
- 修改前後照片（車內、正面、前斜角、上方、車尾、後斜角）並排比對。
- 換行只有 LF、沒有 `__lc`、沒有隱形字元，script 可以解析。
- 使用者試玩確認外型。

## 驗證紀錄

- 照片：`before/` 與 `after/`（不進 git）。車內看得到兩個頭燈之間的引擎蓋；車尾尾燈往內延伸，仍在燈條內；前斜角其他部位不變。
