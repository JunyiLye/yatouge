# GT-32 第二輪修改 — 使用者回饋（2026-11-13）

結論：GT-32 第一輪重做（commit 8998e33）之後，使用者提出三點修改。這些要在 SR-7 修穿模之後處理，同一時間只跑一個 builder。車尾仍然不動。

## 1. 引擎蓋太長
- 把擋風玻璃與車艙前緣往前移約 25–30 cm，讓引擎蓋短約 15–20%。
- 全車長度不變，車尾不動。

## 2. 頭燈看起來是平面的
- 燈組稍微內凹，嵌進車身，外圈是深色框，邊緣有一點深度。
- 透明燈罩略往前凸，會反光。
- 燈罩後面看得到反射杯與投射燈，從斜角看有立體感。
- 琥珀色角燈做成真正繞到側面的立體零件，而不是平的色條。

## 3. 車頭太方（參考 images/24.png、images/25.png）
- 現在的車頭從引擎蓋、頭燈到下巴幾乎都是 90 度直角。
- 改成帶弧度的輪廓：
  - 引擎蓋前緣圓順地往下彎，接到頭燈上緣；
  - 頭燈與水箱罩的面略往後傾，不是垂直的牆；
  - 保險桿從頭燈下方圓順地往前凸，再往下收到下巴；
  - 轉角處（車頭角、保險桿角）也要圓順，從上方與斜前方看都不要有尖角。
- 整體仍然是低、寬、方正感強的 R32 車頭，只是邊角變圓，不能變成流線型跑車。

## 驗證
- 用與第一輪相同的角度拍修改前後的照片（fl、fr、front、side、corner、rear），對照參考照片。
- 車尾照片的差異只能出現在先前已知的位置。
- 從專案根目錄執行 `node --test` 全部通過。
- 一次只開一個瀏覽器、一個分頁；結束時關閉。
