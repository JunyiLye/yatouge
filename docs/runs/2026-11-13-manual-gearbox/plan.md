# 手排變速箱 — 實作計畫

結論：新增手排駕駛模式。每次開始比賽前（單人或線上）都詢問要用自排還是手排，並預選上次的選擇。手排時，Shift 升檔、Z 降檔；手機則在右手拇指附近顯示 ▲／▼ 按鈕。手排有真實的檔位：每一檔的加速力道不同，到紅線時斷油，檔位太高時會拖檔沒力。換得好會比自排稍快。自排的行為必須與現在完全相同。

Pipeline：Frontend Feature SDD — Light Path（單一檔案、無 API、無新相依）。物理有變動，所以手排的平衡要用模擬測試把關。

## 使用者決定（2026-11-13）
- 按鍵：Shift 升檔、Z 降檔。原本想用 Ctrl 降檔，但 Ctrl+W 會關閉分頁，所以改用 Z。
- 手感：換得好會比自排快一點，有紅線斷油，高檔低轉會沒力。
- 手機：右手拇指附近有 ▲ 升檔、▼ 降檔兩個小按鈕。拖曳模式放在油門上方；傾斜與分區模式放在右上角。只有選手排時才顯示。
- 詢問：每次開賽前都問，預選上次的選擇，按一下或按 Enter 就能確認。

## 現況
- 檔位只是顯示用：`gearFor(spd)` 依速度門檻（`GEARS`）推算 1–6 檔。`car.rpm` 依檔位與速度計算，引擎聲、儀表與排檔桿動畫都用它。
- 推進力是 `engineForce(engine, lagF, vf, maxV, pen)`，與檔位無關（`@engine` 區塊，`ACCEL_SCALE` 為 2/3）。

## 設計
1. **模式**：每場比賽有 `trans = 'auto' | 'manual'`。選擇存在 `store` 的 `yatouge-trans`，作為下次的預選值。
2. **開賽前詢問**：
   - 單人按「開始」，或線上房間按「準備」之前，跳出一個小對話框「自排 / 手排」（AT / MT），附上按鍵說明。
   - 預選上次的值，Enter 或點選即確認，Esc 取消並回到原畫面。
   - 線上：對話框在按下準備前出現，選完才送出 ready；倒數同步不受影響。
   - 鍵盤、觸控都要好用，雙語。
3. **手排物理**（純函式，`@gearbox` 區塊）：
   - 每台車有一組 1–6 檔的齒比（可以從現有 `GEARS` 推導），由檔位與車速算出 rpm，紅線約 8000（各車可以不同）。
   - 推進力 = 自排的力 × 該檔的扭力係數（由 rpm 對應的扭力曲線決定：低轉弱、中段強、接近紅線略降）× 檔位係數（低檔力大、高檔力小）。
   - 到紅線時斷油（力量歸零，rpm 卡在紅線並有斷油的抖動聲）。
   - 檔位太高、rpm 低時力量很小（拖檔）。
   - 平衡目標：最佳換檔時機的加速略優於自排（例如 0–100 km/h 快約 3–8%），極速大致相同。用模擬測試確認，並且確保自排的數值完全不變。
   - 換檔：升降檔各有約 0.12 秒的斷油（換檔空檔），R 檔不在手排序列內，倒車沿用現有的「低速按煞車」行為。降檔時若會超過紅線，就拒絕降檔並提示「轉速過高」，或是允許但限制 rpm，由 maker 擇一並說明。
4. **連動**：
   - 手排時，`car.gear` 由玩家控制。HUD 檔位、rpm、引擎聲（含 GT-32 的換檔 flutter）、車內排檔桿動畫都改用實際檔位。
   - 自排時全部維持原樣。
   - **使用者特別要求（2026-11-13）**：車內的排檔桿動畫要與手排一致。每按一次 Shift 或 Z，排檔桿就沿 H 檔的路徑（拉回中線、橫移、推入）移到新的檔位，時機與換檔空檔同步。HUD 顯示的檔位、rpm 下降或上升也同時發生。瀏覽器檢查時要截圖證明，至少截兩個檔位的車內畫面。
5. **按鍵**：
   - Shift 升檔、Z 降檔，只在手排且比賽中（含倒數）有效，忽略按鍵自動重複。
   - 遊戲中選單開啟時無效。
   - 選單「設定」與按鍵說明加上這兩個鍵。
6. **手機**：
   - 手排時才顯示 ▲／▼ 按鈕：拖曳模式放在油門上方，傾斜與分區模式放在右上角。不得與 HUD 或其他控制重疊。
   - 沿用防誤觸設定。
7. **AI 對手與 PvP 對手不受影響**，仍用原本的方式。

## Exit Criteria
1. 從專案根目錄執行 `node --test` 全部通過，0 個失敗。純函式要先寫測試，先紅後綠：
   - 齒比與 rpm；
   - 扭力曲線；
   - 紅線斷油；
   - 拖檔；
   - 換檔空檔；
   - 降檔保護；
   - 模擬結果：最佳換檔比自排快 3–8%，極速相同，永遠只用 1 檔或 6 檔會明顯較慢；
   - 自排的推進力與現在逐值相同。
2. 瀏覽器檢查（一次只開一個瀏覽器，開之前先檢查記憶體）：
   - 開賽前的詢問與預選正常；
   - 手排時 Shift／Z 會改變檔位、HUD、rpm 與聲音；
   - 手機的 ▲／▼ 有效；
   - 自排與現在相同；
   - 線上 mock 流程中，選完才送出 ready；
   - console 沒有錯誤。
3. 結束時關閉所有測試 server 與瀏覽器。
