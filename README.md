# 夜峠下坡（Night Pass Downhill）

夜晚山路下坡甩尾賽車遊戲。單一 HTML 檔，使用 three.js（從 CDN 載入）。打開 `yatouge.html`（或 GitHub Pages 的網址）就能玩。

## 內容

- **3 條賽道**：黑鷺山、青嵐峠（有水溝過彎）、白狼峠（路面較寬）。
- **3 台車**：KX-2 掀背、SR-7 轉子跑車、GT-32 雙渦輪，各有不同的操控與引擎聲。
- **對手**：每條賽道有固定的 AI 對手。
- **其他功能**：甩尾計分、精確碰撞框、三種鏡頭（追蹤、近距離、車內 3D 座艙含後照鏡）、自選背景音樂（檔案只在自己的裝置上播放，不會上傳）。

## 操作

- 方向鍵或 WASD：油門、煞車、轉向。
- 空白鍵：手煞車。
- R：回到路面。
- M：音樂開關。
- C：切換鏡頭。
- Esc（手機為 ☰）：遊戲中選單，包含繼續、設定（音量、鏡頭、語言）與認輸。開啟選單時遊戲不會暫停。
- 自選背景音樂：在主畫面的「聲音設定」視窗選擇。
- 手機：請橫向遊玩（直向時會提示轉向）。轉向方式可在遊戲中選單（☰）的設定中切換，共三種：
  - 拖曳（預設）：左手拇指在左下區域左右滑動是類比轉向，右手拇指操作油門、煞車、手煞車。
  - 傾斜：把手機當方向盤左右傾斜來轉向。油門自動；輕點螢幕是煞車加手煞車，按住是持續煞車。
  - 分區：畫面上半部左右兩半分別是左轉、右轉，下方整排是煞車加手煞車。油門自動。

## 線上對戰

線上 1 對 1 對戰在 GitHub Pages（https://junyilye.github.io/yatouge/）上玩，使用 Supabase Realtime。除了公開房間，也可以建立私人房間，用 4 碼代碼邀請朋友加入。

所有對戰都只顯示暱稱，不使用任何帳號資訊。

## 測試

```
node --test
```

測試會從 `yatouge.html` 抽出純邏輯區塊（以 `/* @名稱:start */ … /* @名稱:end */` 標記）來執行。

## 其他

- 車名與外型為虛構，不含任何真實品牌名稱或標誌。
- `docs/runs/` 是各次修改的計畫、審查與報告紀錄。
